# STM32 外部センサー仕様

[プロジェクトREADME](../README.md) | [資料一覧](README.md) | [コードマップ](コードマップ.md)

## 1. 対象

| 項目 | 仕様 |
|---|---|
| MCU | STM32G473RCT6 |
| バス | I2C1、100 kHz |
| ピン | PA15=SCL、PA14=SDA |
| モーションセンサー | ICM-20948、アドレス`0x68`または`0x69` |
| 地磁気センサー | ICM-20948内蔵AK09916、補助I2Cアドレス`0x0C` |
| 環境センサー | BMP280、アドレス`0x76`または`0x77` |

SWD/JTAGデバッグモードは使用せず、PA14をI2C1 SDAとして使用する。

## 2. 取得構成

```text
ICM-20948
  +-- 加速度 XYZ -------+
  +-- ジャイロ XYZ -----+--> STM32スナップショット --> SPI Version 2
  `-- 内部I2C Master
        `-- AK09916 XYZ -+

BMP280
  `-- 温度・気圧 -------+
```

## 3. ICM-20948

### 3.1 モーションコア

| 項目 | 設定 |
|---|---|
| 識別 | `WHO_AM_I=0xEA` |
| 電源 | 加速度・ジャイロ全軸有効、`PWR_MGMT_2=0x00` |
| 加速度レンジ | ±4 g、8192 LSB/g |
| 加速度LPF | 有効 |
| ジャイロレンジ | ±500 deg/s、65.5 LSB/(deg/s) |
| ジャイロLPF | 有効 |
| 取得周期 | 10 ms |
| 保持単位 | 加速度mg、ジャイロ0.1 deg/s |

加速度とジャイロはUSER BANK 0の`ACCEL_XOUT_H`から12 byteを一括読出しする。

### 3.2 AK09916

AK09916はSTM32のI2C1から直接アクセスせず、ICM-20948の内部I2Cマスターを使用する。

| 項目 | 設定 |
|---|---|
| 識別 | `WIA2=0x09` |
| 動作モード | Continuous measurement mode 4、100 Hz |
| 自動転送 | `ST1`から`ST2`まで9 byte |
| 取得周期 | 10 ms |
| 感度 | 0.15 µT/LSB |
| 保持単位 | 0.1 µT |

`ST1.DRDY=0`はデータ未更新として前回値を保持し、通信エラーへ加算しない。`ST2.HOFL=1`はオーバーフロー異常とする。

地磁気値は未補正である。ロボット搭載後の方位算出にはハードアイアン・ソフトアイアン補正が別途必要となる。

## 4. BMP280

| 項目 | 設定 |
|---|---|
| 識別 | `CHIP_ID=0x58` |
| 取得周期 | 100 ms |
| 温度単位 | 0.01 ℃ |
| 気圧単位 | Pa |

起動時に個体別校正値を読み、データシートの整数補正式を適用する。

## 5. 状態管理

| bit | 値 | 内容 |
|---:|---:|---|
| 0 | `0x01` | 加速度有効 |
| 1 | `0x02` | 温度・気圧有効 |
| 2 | `0x04` | 加速度異常 |
| 3 | `0x08` | 温度・気圧異常 |
| 4 | `0x10` | ジャイロ有効 |
| 5 | `0x20` | ジャイロ異常 |
| 6 | `0x40` | 地磁気有効 |
| 7 | `0x80` | 地磁気異常 |

同一処理で取得する加速度とジャイロは、I2C異常時に同時に無効化する。地磁気初期化だけ失敗した場合、加速度・ジャイロ・BMP280の取得は継続する。

連続3回失敗で対象を無効化し、1秒周期で再初期化する。加速度・ジャイロ・地磁気は250 ms、環境値は1000 ms更新されない場合に無効化する。

## 6. SPI応答

`CMD_SENSOR_REQ(0x20)`に対し`CMD_SENSOR_RESP(0x91)`を返す。Payloadは固定32 byte、Version 2、複数byte値はビッグエンディアンとする。

| Offset | 長さ | 内容 |
|---:|---:|---|
| 0 | 1 | Version `0x02` |
| 1 | 1 | 状態フラグ |
| 2 | 2 | シーケンス |
| 4 | 4 | STM32取得時刻ms |
| 8 | 6 | 加速度X/Y/Z、mg |
| 14 | 6 | ジャイロX/Y/Z、0.1 deg/s |
| 20 | 6 | 地磁気X/Y/Z、0.1 µT |
| 26 | 2 | BMP280温度、0.01 ℃ |
| 28 | 4 | BMP280気圧、Pa |

## 7. 関数

| 関数 | 処理 | 引数 | 戻り値 |
|---|---|---|---|
| `ICM20948_Init` | モーションコアとAK09916を初期化 | デバイス、I2Cハンドル | モーションコアの状態 |
| `ICM20948_InitMagnetometer` | AK09916のみ再初期化 | デバイス | AK09916状態 |
| `ICM20948_ReadMotion` | 加速度・ジャイロ12 byteを取得・変換 | デバイス、2つのXYZ配列 | 取得状態 |
| `ICM20948_ReadMagneticField` | 自動転送済み地磁気を取得・変換 | デバイス、XYZ配列 | 取得状態または`NO_DATA` |
| `ExternalSensors_Poll` | 周期取得・失敗判定・再初期化 | 現在時刻ms | 状態bit |
| `ExternalSensors_GetSnapshot` | 最新値をコピー | 出力先 | なし |

## 8. 受入条件

- 静止時に加速度1軸が約±1000 mgとなる。
- 静止時のジャイロ各軸が概ね0 deg/s付近となる。
- 回転方向に対応してジャイロ軸の符号と値が変化する。
- 姿勢変更に対応して地磁気3軸が変化する。
- BMP280の温度・気圧が有効となる。
- `CMD_SENSOR_REQ`に32 byte、Version 2の応答が返る。
