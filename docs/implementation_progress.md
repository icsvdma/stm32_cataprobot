## 実装方針

- 時刻を入力に取る純粋なCのモーター安全制御と、タイマ・GPIOのアダプターを分ける。
- モーター安全状態、SPIパケット処理、ESP32の操作・応答判定を公開インターフェースで試験する。
- 制御更新を高優先度の1 msシステムタイマから5 msごとに呼び、センサー待ちに依存させない。
- NSS境界処理を割り込みで行い、センサー復旧中も次の取引を受理する。
- 新プロトコルは走行許可の世代番号で、停止前の指令を拒否する。
- バックアップレジスターで緊急停止・シャットダウンを保持する。VBATが別給電なら、その給電も含めた完全電源断を解除条件とする。BORだけでは解除しない。
- 制御更新が10 msを超えて遅れた場合は出力ゼロ・再開待ちとする。

上記の追加判断は、質問を止めず推奨案で進めて後で確認するというユーザー方針に基づく。
