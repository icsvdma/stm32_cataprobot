## 1. 対象構成

| 項目 | 仕様 |
|---|---|
| 制御MCU | ESP32、STM32G473RCT6 |
| モーター駆動 | 2ch Hブリッジモータードライバ回路 |
| 9軸モーションセンサー | ICM-20948（加速度・ジャイロ・AK09916地磁気） |
| 温度・気圧センサー | BMP280 |
| MCU間通信 | SPI Mode 0、1 MHz |

## 2. ブロック図

## 3. STM32センサー接続

| STM32端子 | 機能 | 接続先 | GPIO設定 |
|---|---|---|---|
| `PA15` | `I2C1_SCL`、AF4 | ICM-20948 SCL、BMP280 SCL | Open Drain、No Pull |
| `PA14` | `I2C1_SDA`、AF4 | ICM-20948 SDA、BMP280 SDA | Open Drain、No Pull |
| 3.3 V | センサー電源 | 両センサーモジュール | - |
| GND | 共通GND | 両センサーモジュール | - |

SDA/SCLは各4.7 kΩを初期候補として3.3 Vへプルアップする。モジュール上の実装済み抵抗を確認し、並列合成抵抗が小さくなり過ぎないようにする。

`PA14`はSWCLKと端子機能が重複するが、本システムはSWD/JTAGデバッグモードを使用しないため、I2C1 SDAとして使用する。

## 4. I2C仕様

| 項目 | 仕様 |
|---|---|
| バス | I2C1 |
| 速度 | 100 kHz |
| 信号電圧 | 3.3 V |
| ICM-20948アドレス | `0x68`または`0x69` |
| BMP280アドレス | `0x76`または`0x77` |
| STM32内部プルアップ | 使用しない |

5 VへプルアップされたI2C信号は接続しない。市販モジュールを使用する場合は、電源回路、レベル変換、プルアップ先電圧を回路図または実測で確認する。

## 5. センサー仕様

| センサー | 測定対象 | 設定 | 取得周期 | 出力 |
|---|---|---|---:|---|
| ICM-20948 | 3軸加速度 | ±4 g、8192 LSB/g | 10 ms | X/Y/Z、mg |
| ICM-20948 | 3軸ジャイロ | ±500 deg/s、65.5 LSB/(deg/s) | 10 ms | X/Y/Z、0.1 deg/s |
| AK09916 | 3軸地磁気 | 0.15 µT/LSB、100 Hz連続測定 | 10 ms | X/Y/Z、0.1 µT |
| BMP280 | 温度・気圧 | 温度x1、気圧x4、normal mode | 100 ms | 0.01 ℃、Pa |

AK09916はICM-20948内部I2Cマスターからアクセスする。地磁気値は未補正とし、方位算出時は搭載状態でハードアイアン・ソフトアイアン補正を行う。BMP280は起動時に個体別校正値を読み出し、測定値へ補正式を適用する。

## 6. SPI接続

| 項目 | 仕様 |
|---|---|
| Master | ESP32 |
| Slave | STM32G473RCT6 |
| Mode | 0 |
| Clock | 1 MHz |
| Signals | SCK、MOSI、MISO、NSS、GND |

SPI配線はモーター電力配線から離し、GNDリターンを明確にする。センサー応答用にESP32は64 byteのpaddingを同一NSS期間で送信する。

## 7. モーター駆動

STM32のTIM8 CH1～CH4から20 kHz PWMを出力し、2ch Hブリッジ回路を制御する。正転、逆転、ブレーキに対応し、方向反転時は速度0、100 msデッドタイムを経て方向を切り替える。

ロジック電源とモーター電源のGNDを共通化し、モーター端子のノイズ抑制、電源デカップリング、電力配線と信号配線の分離を行う。

## 8. ヘッドライト・バッテリー監視

### 8.1 ヘッドライト

| 項目 | 仕様 |
|---|---|
| 右 / 左出力 | PA0 / PA1 |
| タイマ | TIM2 CH1 / CH2 |
| PWM周波数 | 1 kHz |
| 光量 | 0〜100% |

### 8.2 バッテリー監視

| 項目 | 仕様 |
|---|---|
| バッテリー | 12Vバイク用鉛バッテリー |
| ADC | ESP32 GPIO34 / ADC1_CH6 |
| 分圧 | 100 kΩ / 33 kΩ |
| 取得周期 | 200 ms |
| 平均 | 4サンプル |
| 表示 | PS3 Player LED 1〜4 |
| 表示境界 | 12.1 V、12.4 V、12.6 V |
| ヒステリシス | 100 mV |

電圧表示は開放電圧を基準とするが、実機ではモーター負荷中の端子電圧を測定するため残量の目安として扱う。
100 kΩ / 33 kΩ分圧と3.3 V換算の測定上限は約13.3 Vである。14 V台になる充電器または車体充電系を接続した状態では使用せず、必要な場合は分圧比と入力保護を再設計する。

## 9. 検証項目

- PA15/PA14で100 kHzのI2C波形とACKを確認する。
- SDA/SCL待機時電圧が3.3 Vであることを確認する。
- ICM-20948の`WHO_AM_I=0xEA`を確認する。
- AK09916の`WIA2=0x09`を確認する。
- 加速度、ジャイロ、地磁気の各3軸が姿勢・回転に追従して変化することを確認する。
- BMP280の`id=0x58`を確認する。
- モーター回転中もI2C/SPIエラーが継続しないことを確認する。
- 片方のセンサーを外した場合、他方とモーター制御が継続することを確認する。
- ▲押下ごとに左右ヘッドライトが10、25、50、70、0%へ遷移することを確認する。
- PS3切断時にヘッドライトが0%になることを確認する。
- 12.1 V、12.4 V、12.6 Vの境界でPlayer LEDが切り替わることを確認する。
