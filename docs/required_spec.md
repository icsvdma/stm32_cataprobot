## ESP32・STM32 CataProbot制御システム

| 項目 | 内容 |
|---|---|
| バージョン | 2.1 |
| 更新日 | 2026-07-23 |
| 状態 | 現行実装 |

## 1. 目的

PS3コントローラーによる2ch DCモーターとヘッドライトの制御、12Vバイク用鉛バッテリーの電圧表示、STM32に接続した外部センサーのリアルタイムWeb監視を実現する。モーターは2ch Hブリッジモータードライバ回路で駆動し、センサーはICM-20948とBMP280を使用する。

## 2. システム構成

```text
PS3 Controller ─Bluetooth─ ESP32 ─SPI─ STM32G473 ─PWM─ 2ch Hブリッジ回路
      ▲操作 / Player LED         │          ├─PWM─ 左右ヘッドライト
                                 │          └─I2C1─ ICM-20948 / BMP280
                                 ├─ADC─ 12Vバイク用鉛バッテリー
                                 └─Wi-Fi SoftAP / HTTP─ Webブラウザ
```

## 3. 機能要件

### 3.1 ESP32

| ID | 要件 |
|---|---|
| E-01 | PS3左スティックYと右スティックXから左右モーター指令を生成すること |
| E-02 | モーター指令をSPI Mode 0、1 MHzでSTM32へ送信すること |
| E-03 | 100 ms周期で`CMD_SENSOR_REQ(0x20)`を送信すること |
| E-04 | `CMD_SENSOR_RESP(0x91)`のVersion 2、32 byteペイロードを検証・変換すること |
| E-05 | SoftAP `CataProbot-Monitor`を起動すること |
| E-06 | `GET /api/sensors`で最新値をJSON提供すること |
| E-07 | Web画面へ9軸、温度、気圧、個別状態、3つの30秒グラフを表示すること |
| E-08 | モーターとセンサーのSPI処理をmutexで排他すること |
| E-09 | センサー通信異常だけではモーター制御を停止しないこと |
| E-10 | ▲押下ごとにヘッドライトを10、25、50、70、0%の順で切り替えること |
| E-11 | PS3切断時にヘッドライトを0%へ戻すこと |
| E-12 | 12V鉛バッテリー電圧を4回平均してPlayer LED 1〜4へ表示すること |
| E-13 | Player LED境界を12.1 V、12.4 V、12.6 Vとし、100 mVのヒステリシスを設けること |
| E-14 | Player LEDコマンドはPS3接続時または表示段階変更時だけ送信すること |

### 3.2 STM32

| ID | 要件 |
|---|---|
| S-01 | 2ch Hブリッジ回路へ20 kHz PWMと方向信号を出力すること |
| S-02 | I2C1を`PA15=SCL`、`PA14=SDA`、100 kHzで使用すること |
| S-03 | SWD/JTAGデバッグモードを使用しないこと |
| S-04 | ICM-20948から加速度・ジャイロ・地磁気の9軸を100 Hzで取得すること |
| S-05 | BMP280から温度・気圧を10 Hzで取得し、個体別校正値で補正すること |
| S-06 | 最新センサー値、有効状態、取得時刻をスナップショットとして保持すること |
| S-07 | センサー要求時はI2Cアクセスせず、最新スナップショットを応答すること |
| S-08 | 3回連続エラーで対象センサーを無効化し、1秒周期で再初期化すること |
| S-09 | I2Cタイムアウトやセンサー故障時もモーター処理を継続すること |
| S-10 | TIM2 CH1/CH2から左右ヘッドライトへ1 kHz、0〜100% PWMを出力すること |

## 4. 通信要件

### 4.1 SPI

| 項目 | 要件 |
|---|---|
| Master / Slave | ESP32 / STM32 |
| 速度 | 1 MHz |
| Mode | 0 |
| パケット | `[0xAA][CMD][LEN][PAYLOAD][XOR]` |
| 応答padding | 64 byte |

### 4.2 センサーペイロード

`CMD_SENSOR_RESP(0x91)`はVersion 2とし、状態、シーケンス、STM32取得時刻、X/Y/Z加速度mg、X/Y/Zジャイロ0.1 deg/s、X/Y/Z地磁気0.1 µT、温度0.01 ℃、気圧Paを固定32 byteで返す。複数byte値はビッグエンディアンとする。

### 4.3 Web

| 項目 | 要件 |
|---|---|
| 接続先 | `CataProbot-Monitor` / `cataprobot` |
| URL | `http://192.168.4.1/` |
| API周期 | ブラウザから100 ms |
| キャッシュ | 無効 |
| stale判定 | ESP32受信から500 ms超 |

## 5. 非機能要件

- センサーI2C処理は1トランザクション10 ms以内でタイムアウトすること。
- モーター制御とセンサー取得は互いの異常で停止しないこと。
- Web画面は外部CDNやフォントへ依存せずESP32単体で配信できること。
- 2 MBフラッシュへ格納できる単一factoryパーティションを使用すること。
- センサー値が無効または古い場合、Web画面は数値を正常値として表示し続けないこと。
- 100 kΩ / 33 kΩ分圧による測定上限を約13.3 Vとし、14 V台の充電中測定には使用しないこと。

## 6. 受入条件

- STM32とESP32の両ファームウェアがエラーなくビルドできる。
- I2C1のピンが`PA15/PA14`で、デバッグモードが無効になっている。
- ブラウザで100 msごとに値と状態が更新される。
- 加速度・ジャイロ・地磁気の各グラフが直近300点、約30秒を保持する。
- センサー切断時に異常表示へ遷移し、モーター制御は継続する。
- ▲押下ごとに左右ヘッドライトが10、25、50、70、0%へ遷移する。
- PS3切断時にヘッドライトが0%になる。
- 12.1 V、12.4 V、12.6 Vの境界に従ってPlayer LEDが切り替わる。
