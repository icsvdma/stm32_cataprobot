# STM32コードマップ

[プロジェクトREADME](../README.md) | [資料一覧](README.md)

## 処理の流れ

```text
ESP32 SPI要求
  -> SPI1_IRQHandler
  -> SPI_Slave_IRQHandler
  -> SPI_Slave_Dispatch
  -> HBridge / LED / Sensor応答

I2Cセンサー
  -> ExternalSensors_Poll
  -> ICM20948 / BMP280
  -> ExternalSensorSnapshot_t
  -> prepare_sensor_response
  -> ESP32
```

## 独自コード

| ファイル | 役割 | 最初に見る関数・定義 |
|---|---|---|
| `Core/Inc/config.h` | ピン、通信コマンド、安全時間 | `PIN_*`、`CMD_*` |
| `Core/Inc/packet.h` | ESP32と共通のパケット形式 | `Packet_t` |
| `Core/Src/packet.c` | パケット生成、バイト列化、検証 | `Packet_Parse` |
| `Core/Inc/spi_comm.h` | SPIスレーブ公開API | `SPI_Slave_*` |
| `Core/Src/spi_comm.c` | 割り込み受信、コマンド処理、応答生成 | `SPI_Slave_Dispatch` |
| `Core/Inc/motor_hbridge.h` | Hブリッジ公開API | `HBridge_SetMotor` |
| `Core/Src/motor_hbridge.c` | PWM、加減速、方向反転 | `update_channel` |
| `Core/Inc/led_control.h` | ヘッドライト公開API | `LED_SetBrightness` |
| `Core/Src/led_control.c` | PWM光量と点灯パターン | `LED_Update` |
| `Core/Inc/external_sensors.h` | 最新値と状態ビット | `ExternalSensorSnapshot_t` |
| `Core/Src/external_sensors.c` | 取得周期、再試行、期限切れ管理 | `ExternalSensors_Poll` |
| `Core/Inc/icm20948.h` | 9軸センサー公開API | `ICM20948_t` |
| `Core/Src/icm20948.c` | 加速度、ジャイロ、AK09916制御 | `ICM20948_Init` |
| `Core/Inc/bmp280.h` | 温度・気圧センサー公開API | `BMP280_t` |
| `Core/Src/bmp280.c` | 補正値読み込みと物理量計算 | `BMP280_ReadTemperaturePressure` |
| `Core/Src/debug_led.c` | 状態確認LED | `DebugLed_Update` |
| `Core/Src/uart_comm.c` | 保守用UART互換経路 | `UART_ProcessReceived` |

表内の`Core`は`cubeMX_stm32g473_test/Core`を表します。

## CubeMX生成コードとの接続点

| ファイル | 独自処理との接続 |
|---|---|
| `Core/Src/main.c` | 周辺機能初期化後に各独自モジュールを初期化し、メインループで更新 |
| `Core/Src/stm32g4xx_it.c` | `SPI1_IRQHandler`から専用SPIハンドラーを呼び出す |
| `Core/Src/stm32g4xx_hal_msp.c` | I2C1、SPI1、TIM2、TIM8、USART2のクロックとGPIOを設定 |
| `cubeMX_stm32g473_test.ioc` | CubeMXで再生成する周辺機能設定 |

CubeMXで再生成する場合は、`USER CODE BEGIN`と`USER CODE END`の外側にある手動変更が失われないか差分を確認してください。

## 主要コマンドと処理先

| コマンド | 処理関数 | 制御先 |
|---|---|---|
| `CMD_MOTOR_SPEED(0x01)` | `handle_motor_speed` | `HBridge_SetMotor` |
| `CMD_MOTOR_STOP(0x02)` | `handle_motor_stop` | `HBridge_Stop` |
| `CMD_EMERGENCY_STOP(0x04)` | `handle_emergency_stop` | `HBridge_EmergencyStop` |
| `CMD_LED_MODE(0x11)` | `handle_led_mode` | `LED_SetMode` |
| `CMD_LED_BRIGHTNESS(0x12)` | `handle_led_brightness` | `LED_SetBrightness` |
| `CMD_SENSOR_REQ(0x20)` | `prepare_sensor_response` | 最新32 byte値を応答 |
| `CMD_SHUTDOWN(0x30)` | `SPI_Slave_Dispatch` | モーター、ライト、LED停止 |

## 変更するときの目安

| 変更内容 | 主に変更する場所 |
|---|---|
| モーターPWM周波数 | `motor_hbridge.c`の`HBRIDGE_PWM_FREQ_HZ` |
| 加減速速度 | `HBRIDGE_SLEW_RATE` |
| 方向反転待ち | `HBRIDGE_REVERSE_WAIT_MS` |
| ライトPWMや点灯周期 | `led_control.c`の定数 |
| センサー取得周期 | `external_sensors.c`の`*_PERIOD_MS` |
| ICMレンジ | `ICM20948_Init`のBank 2設定 |
| SPIデータ配置 | `prepare_sensor_response`とESP32側`decodeResponse` |

SPIデータ配置を変更する場合は、ESP32の`SENSOR_RESPONSE_VERSION`も更新してください。
