# STM32ドキュメント一覧

[プロジェクトREADME](../README.md) | [コードマップ](コードマップ.md)

## 読む順番

1. [プロジェクトREADME](../README.md)で構成、ピン、ビルド方法を確認する。
2. [コードマップ](コードマップ.md)で機能とファイルの対応を確認する。
3. [要件定義書](required_spec.md)でシステムが満たす内容を確認する。
4. 変更対象に応じて設計書、SPI、センサー、ハードウェア資料を読む。

## 文書の役割

| 文書 | 目的 | 主な読者 |
|---|---|---|
| [コードマップ](コードマップ.md) | 機能、ファイル、主要関数の対応を探す | 初めてコードを見る人 |
| [要件定義書](required_spec.md) | ESP32・STM32全体の要求と受入条件を確認する | 利用者、試験担当 |
| [コード設計書](code_design.md) | PS3入力からモーター・センサーまでの設計を確認する | 実装担当 |
| [SPIコマンドリファレンス](spi_command_reference.md) | パケット、コマンド、データ配置を確認する | 通信実装担当 |
| [外部センサー仕様](STM32_外部センサ仕様.md) | ICM-20948とBMP280の設定・取得周期を確認する | センサー実装担当 |
| [ハードウェア仕様書](hardware_spec_template.md) | ピン、I2C、SPI、Hブリッジ配線を確認する | 回路・実装担当 |
| [実装計画・実績](implementation_plan.md) | 実装済み項目と実機確認項目を確認する | 管理・試験担当 |
