# 走行安全プロトコル Version 1

パケット外枠とXORは既存SPI仕様と同じ。複数byteはビッグエンディアン。センサー応答Version 2・32 byteは変更しない。

| CMD | ペイロード | 応答 |
|---|---|---|
| `0x03` 左右同時指令 | 世代`uint16`、左`int16`、右`int16`。各-1000〜1000 | ACK/NACK |
| `0x05` 走行許可 | 形式版`1`、世代`uint16` | ACK/NACK |
| `0x06` 停止保持 | 理由`3=PS3切断`、`4=応答異常` | ACK/NACK |
| `0x10` 状態要求 | 形式版`1` | `0x90`、16 byte |
| `0x01` 旧速度指令 | 旧形式 | NACK `0x04`。走行させない |
| `0x02` 通常停止 | 従来の対象ch | ACK/NACK。許可状態を解除しない |
| `0x04` 緊急停止 | なし | ACK/NACK。電源断まで保持 |
| `0x30` シャットダウン | なし | `0xF0`。電源断まで保持 |

## 状態応答

| Offset | 内容 |
|---:|---|
| 0 | プロトコル版`1` |
| 1 | 状態: `0=再開待ち,1=走行許可,2=緊急停止保持,3=シャットダウン保持` |
| 2 | 理由: `0=起動,1=なし,2=指令期限,3=PS3切断,4=応答異常,5=緊急停止,6=シャットダウン,7=制御遅延` |
| 3 | 対応機能bit: `0=左右同時,1=走行許可,2=停止保持`。現行`0x07` |
| 4〜5 | 状態世代番号 |
| 6〜7 / 8〜9 | 現在の左右PWM指令、各`int16` |
| 10〜11 | 古い側のモーター指令からの経過ms。65535で飽和 |
| 12〜15 | STM32起動後ms、`uint32` |

再開待ちでは、現世代の左右ゼロ指令を50 msごとに送る。受信間隔100 ms以内で300 ms継続した後、同世代の走行許可を要求できる。操作者のSTART新規押下はESP32で確認する。

異常停止への移行で世代が進み、古い指令・走行許可を拒否する。通常停止は指定chだけを減速し、そのchの期限だけを更新する。センサー要求・状態照会・ライト操作でモーター指令の期限は更新しない。

NACKは`[元CMD][理由]`。理由`0x02=値/長さ不正,0x03=状態/世代不一致,0x04=非対応形式`。ACKは元CMDが一致する場合だけ成功と扱う。

NSS Highは取引間で10 µs以上確保する。NSS境界を割り込み処理し、メインループの進行には依存しない。

緊急停止・シャットダウンの保持にTAMPバックアップレジスター0/1を使用する。ソフトリセット・IWDG・BORでは解除しない。解除にはVDD/VBAT双方の完全電源断が必要。VBATの実配線は走行前に確認する。
