## 1. 対象

STM32によるICM-20948 9軸/BMP280取得、SPI転送、ESP32 Webモニタリングまでを対象とする。I2C1は`PA15=SCL`、`PA14=SDA`の元仕様を使用し、SWD/JTAGデバッグモードは使用しない。

```text
       ▼

       │ HTTP
       ▼
Webブラウザ
```

## 4. 実装方針

- STM32はセンサーを自律的にポーリングし、SPI要求では保持済みの値だけを返す。
- I2C通信は10 msでタイムアウトし、3回連続失敗で無効化する。
- 無効センサーは1秒周期で再初期化する。
- ESP32は100 ms周期でセンサー要求し、500 msを超えた値をstaleとする。
- Web UIはESP32内の静的HTML/CSS/JavaScriptとして保持し、外部依存を持たない。
- センサー異常をモーター停止条件へ接続しない。

## 5. 追加の実機確認

| 試験 | 合格条件 |
|---|---|
| I2C波形 | PA15/PA14で約100 kHz、3.3 V、ACKあり |
| ICM静止値 | 1軸が約±1000 mg、他軸が約0 mg |
| BMP値 | 室温・大気圧として妥当 |
| SPI応答 | `0x91`、LEN=32、Version 2、XOR正常 |
| Web更新 | 100 ms周期で値とグラフが更新 |
| センサー切断 | 異常表示となり、モーター操作は継続 |
| 長時間運転 | 値停止、タスク停止、過度なSPIエラー増加がない |
